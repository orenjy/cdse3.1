# 📈 삼성전자 vs 애플 주가 트렌드 및 변동성 시계열 분석 프로젝트

> **2023-01-01 ~ 2024-12-31 시계열 데이터 분석 및 인사이트 리포트**

본 프로젝트는 파이썬 `yfinance` 라이브러리를 활용하여 한·미 대표 테크 기업인 **삼성전자(005930.KS)**와 **애플(AAPL)**의 2개년 일봉 주가 데이터를 수집, 정제하고 시계열 기법(20일 이동평균선, 일일 수익률, 롤링 변동성)을 적용하여 분석한 프로젝트입니다.

## ⚡ 빠른 시작 (Quick Start)

### 1. 가상환경 및 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 파이썬 스크립트 실행 (GUI 팝업 차트 확인)
```bash
python analysis.py
```
- 데이터 자동 수집 및 결측치 전처리
- 화면에 차트 1부터 차트 4까지 차례대로 팝업 창이 뜸
- `images/` 폴더에 고해상도 PNG 차트 자동 저장 및 콘솔에 핵심 통계 출력

### 3. 주피터 노트북 실행
VS Code 또는 Jupyter Notebook에서 `analysis.ipynb`를 열고 **Run All**을 실행합니다.
